# 💖 Heart Quest - Modern Dating App

Heart Quest is a sleek and modern dating app developed using Kotlin and Android Studio. Designed to help people connect and build meaningful relationships, Heart Quest offers an intuitive user experience, stylish interface, and smooth navigation – all tailored for the digital age of romance.

---

## 📱 Features

- 🧠 Smart profile matching
- 💬 Real-time messaging (Coming soon)
- 🔍 Profile discovery and search
- ❤️ Like & match functionality
- 🎨 Modern, clean UI design
- 🔐 Secure user authentication

---

## 🚀 Technologies Used

- Kotlin
- Android Studio
- XML for UI Design
- Firebase (Optional for authentication and database)
- Jetpack Libraries (e.g., Navigation, LiveData, ViewModel)
